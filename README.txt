Lekke Lokal Setup Instructions

1. Import database/database.sql into phpMyAdmin.
2. Make sure the database name is lekke_lokal.
3. Copy includes/db_example.php and rename the copy to includes/db.php.
4. Copy includes/email_config_example.php and rename the copy to includes/email_config.php.
5. Start Apache and MySQL in XAMPP.
6. Open the project in the browser through localhost.
7. SMTP email sending is disabled in the submitted source code for security reasons.
8. The hosted version can be accessed at: https://lekkelokal.infinityfree.io
